# 前台靜態圖片、Logo、Favicon 尺寸清單

整理日期：2026-11-09
範圍：`resources/views`（前台 Blade）與 `public/`。後台 SPA 的圖示不在此範圍。

## 1. 需要設計的素材

| 用途 | 檔案 | 目前尺寸 | 實際顯示 | 建議設計尺寸 |
|---|---|---|---|---|
| Logo（頁首） | 後台「網站設定」上傳（`site.logo_url`） | 無預設檔 | 高度固定 40px，寬度自動 | 高 80px（2x），橫式，透明背景 PNG 或 SVG |
| OG 分享圖 | `public/images/og-default.jpg` | **檔案不存在** | 社群分享預覽 | 1200×630，JPG |
| Favicon（SVG） | `public/favicon.svg` | viewBox 235×148 | 瀏覽器分頁 | 方形 viewBox（1:1） |
| Favicon（PNG） | `favicon-32x32.png`、`favicon-16x16.png` | 32、16 | 瀏覽器分頁 | 32×32、16×16 |
| favicon.ico | `public/favicon.ico` | 48×48 | 舊瀏覽器 | 內含 48、32、16 |
| Apple Touch Icon | `apple-touch-icon.png` | 180×180 | iOS 主畫面 | 180×180，不透明背景，不要圓角 |
| PWA 圖示 | `android-chrome-192x192.png`、`android-chrome-512x512.png` | 192、512 | Android 主畫面 | 192×192、512×512，主體留 10% 以上安全邊距 |
| 關於頁主視覺 | `public/images/about-hero.png` | 1536×1024（1.1 MB） | 滿版背景，`object-fit: cover`，容器放大到 120% 做視差 | 1920×1280 以上，建議改 JPG/WebP，壓到 300 KB 內 |

## 3. 需要先處理的問題

1. **Logo 檔名不一致。** `home`、`about`、`news/show`、`knowledge/show` 的 JSON-LD 使用 `asset('images/logo.png')`，但實際檔案是 `logo.jpg`，會 404。修法：把檔案改名為 `logo.png`，或改程式碼。
2. **`og-default.jpg` 不存在。** 後台沒設定 Logo 時，OG 圖會 404。目前 OG 圖直接拿 Logo（`_meta.blade.php:20`），橫式小圖在社群預覽效果差，建議另做 1200×630。
3. **後台 Logo 上傳沒有尺寸限制**，只限圖片、5 MB 以內（`ImageUploadController.php:22`）。
4. **頁尾、手機選單不使用 Logo 圖片**，而是內建 SVG 圖示加網站名稱（`footer.blade.php`、`header.blade.php`）。只有桌機頁首會顯示後台上傳的 Logo。設計新 Logo 時要決定是否統一。
5. **`site.webmanifest` 的 `name` 與 `short_name` 是空字串**，PWA 安裝時沒有名稱。
6. **`favicon.svg` 不是正方形**（235×148），分頁上會被壓扁或留白。

## 4. 設計建議

- **Logo：** 做深色與淺色兩版。首頁頁首是透明疊在主視覺上（文字白色），其他頁為靜態頁首。
- **品牌色：** `theme-color` 為 `#062F71`，強調色 `#168BD2`，深色背景 `#071A2B`。
- **關於頁主視覺：** 左側有深色漸層遮罩（左 95% → 右 30% 不透明），主體請放在畫面右側。
